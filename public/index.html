    Spend

    At 80% of an agent's budget you get an alert; at its budget its session is closed until you raise it (Edit on the agent). At the daily limit no new agents start or resume until tomorrow; running ones go on.

    Clean up old agents

    Closing an agent ends its session; resume it any time. Deleting removes it from your list, with the worktree AI Agent Manager created (Claude's own transcripts stay). Never touched: agents marked Keep, agents working or setting up, and members of a team that is still going. Not deleted: agents with an open pull request, or with uncommitted changes or commits that aren't on any other branch.
